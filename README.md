# One-Liner Marathon

A one-line comedy joke entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) on make.fun.

The program writes a single original one-line joke (1–280 characters) to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
